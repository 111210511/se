# hw5 Kanban Board - 個人專案任務看板

這是一個使用 HTML5、CSS3 與 Vanilla JavaScript 打造的輕量化任務看板系統。本專案無須依賴任何外部框架 (如 React 或 Vue)，直接運用瀏覽器原生的 Drag and Drop API 實作流暢的卡片拖曳功能，非常適合用於個人時間管理、作業進度追蹤以及敏捷開發模擬。

## 系統需求與安裝
請確保使用現代網頁瀏覽器 (支援 HTML5 特性)。
1. 複製專案：將 `index.html` 下載或複製到本地目錄。
2. 執行方式：直接使用瀏覽器開啟 `index.html` 即可使用，或部署至 GitHub Pages。
3. 依賴套件：純前端實作，**完全無需安裝後端伺服器或資料庫**。

## 核心功能列表

### 1. 任務生命週期管理
* **三階段狀態**：內建「待辦事項 (To Do)」、「進行中 (In Progress)」與「已完成 (Done)」三個核心工作直行。
* **快速新增**：在待辦事項區塊提供輸入框，支援點擊按鈕或直接按下 Enter 鍵快速建立任務。
* **獨立刪除**：每張任務卡片皆附有刪除按鈕，點擊並確認後即可安全移除。

### 2. 互動與使用者體驗
* **拖放功能 (Drag and Drop)**：使用滑鼠長按任務卡片即可將其拖曳，跨區塊放置即可改變任務狀態。
* **視覺回饋**：拖曳過程中，原卡片會呈現半透明狀態，目標放置區塊會改變背景顏色提示，提供直覺的操作體驗。

### 3. 資料持久化 (Data Persistence)
* **本機儲存 (LocalStorage)**：所有的任務新增、刪除與狀態變更，都會即時寫入瀏覽器的 LocalStorage 中。
* **狀態保留**：即使重新整理網頁或關閉瀏覽器，再次開啟時依然會還原上一次的任務狀態與位置。

## 實用測試範例

1. **新增測試**：在左側「待辦事項」下方的輸入框輸入「完成軟體工程作業 5」，按下 Enter，確認卡片成功產生。
2. **拖放測試**：按住剛剛產生的卡片，將其拖曳到中間的「進行中」區塊並放開，確認卡片成功轉移。
3. **儲存測試**：按下鍵盤 `F5` 重新整理網頁，確認該任務卡片依然停留在「進行中」區塊。
4. **刪除測試**：點擊卡片右側的 `X` 按鈕，點選確認，驗證卡片消失且重新整理後也不會再出現。
