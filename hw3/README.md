# hw3 MyAccounting - 實用網頁記帳程式
學號 111210511

MyAccounting 是一個使用 HTML、CSS 與 JavaScript 打造的純前端網頁記帳工具。本專案結合了瀏覽器的 LocalStorage 技術，讓使用者在網頁上新增的每一筆收支紀錄都能永久保存在本機端，即使關閉或重新整理網頁，資料依然不會遺失，是一套可以直接應用於日常生活的輕量化記帳方案。

## 系統需求與安裝
請確保使用現代網頁瀏覽器 (如 Chrome, Edge, Safari, Firefox)。
1. 複製專案：將 `index.html` 下載或複製到本地目錄。
2. 安裝依賴套件：本專案為靜態網頁與 Vanilla JavaScript，**無需安裝任何資料庫或後端伺服器**。

## 核心功能與介面列表
本系統包含以下主要互動區塊，將檔案上傳至 GitHub Pages 後即可存取：

### 財務儀表板
| 功能 | 說明 |
|---|---|
| 總結算顯示 | 自動計算並顯示「總收入」、「總支出」以及「本月結餘」 |
| 狀態動態變色 | 結餘為正數時顯示綠色，透支時顯示紅色，方便快速掌握財務健康度 |

### 記帳操作
| 介面 | 說明 |
|---|---|
| 收支切換 | 支援透過下拉式選單選擇該筆紀錄為「收入」或「支出」 |
| 資料驗證 | 內建防呆機制，若未輸入名稱或金額小於等於 0，將跳出警告阻擋 |
| 本機儲存 | 透過 HTML5 LocalStorage API，將陣列資料 JSON 化後存入瀏覽器快取 |

### 紀錄清單
| 介面 | 說明 |
|---|---|
| 日期排序 | 程式會自動將紀錄依照日期「由新到舊」進行排序 |
| 單筆刪除 | 提供獨立的刪除按鈕，點擊並確認後可將錯誤的帳目移除並重新計算總和 |
