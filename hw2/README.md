# hw2 NQU-SIS - 金門大學校務系統前端模擬
學號 111210511

NQU-SIS 是一個使用 HTML、CSS 與 JavaScript 打造的靜態網頁專案，模擬了國立金門大學校務系統的核心介面。本專案專為 GitHub Pages 部署設計，支援網頁前端的路由模擬與資料呈現，無須架設後端資料庫即可展示完整的網頁互動體驗。

## 系統需求與安裝
請確保使用現代網頁瀏覽器 (如 Chrome, Edge, Safari, Firefox)。
1. 複製專案：將 `index.html` 下載或複製到本地目錄。
2. 安裝依賴套件：本專案僅依賴瀏覽器內建環境，**無需安裝額外模組或伺服器**。

## 核心功能與介面列表
本系統包含以下主要互動區塊，將檔案上傳至 GitHub Pages 後即可存取：

### 登入與驗證
| 功能 | 說明 |
|---|---|
| 登入介面 | 模擬校務系統的登入畫面，支援任意帳號密碼進行測試登入 |
| 狀態防護 | 透過 JavaScript 進行基礎狀態控制，未登入前隱藏內部儀表板 |

### 學生資訊展示
| 介面 | 說明 |
|---|---|
| 個人資料 | 顯示登入者的學號、系所與學籍狀態 |
| 學生課表 | 展示模擬的當學期選課清單與上課時間表 |
| 歷年成績 | 以表格方式模擬顯示歷年修課成績與學分統計 |
